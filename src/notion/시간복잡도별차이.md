# 🔥 시간 복잡도 비교

시간 복잡도는 **입력 크기 `n`이 커질 때 알고리즘의 실행 횟수가 어떻게 증가하는지**를 나타내는 개념이다.  
아래 표는 다양한 알고리즘의 수행 횟수와 시간 복잡도를 비교한 것이다.

---

## 📌 시간 복잡도 비교표

| 알고리즘 유형 | 수행 횟수 예시 | 시간 복잡도 | 의미 |
|-------------|-------------|------------|------|
| **상수 시간** | `T(n) = 1` | `O(1)` | 입력 크기와 관계없이 항상 같은 실행 횟수 |
| **선형 시간** | `T(n) = n` | `O(n)` | 입력 크기에 비례해서 증가 |
| **제곱 시간** | `T(n) = n²` | `O(n²)` | 입력 크기가 커질수록 실행 횟수 폭발적으로 증가 |
| **로그 시간** | `T(n) = log n` | `O(log n)` | 입력 크기가 증가해도 실행 횟수가 느리게 증가 |
| **팩토리얼 시간** | `T(n) = n!` | `O(n!)` | 엄청나게 빠르게 증가, 보통 비효율적 |
